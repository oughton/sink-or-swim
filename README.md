# Sink or Swim

A browser game: the ship is sinking, so jump overboard and swim for the island. Climb onto icebergs to escape hungry sharks, rest to get your stamina back, and hop off again when the coast is clear. Race against bots to be first ashore.

**Play:** https://oughton.github.io/sink-or-swim/

## Controls

| Action | Keyboard | Touch |
| --- | --- | --- |
| Move | Arrow keys | Drag anywhere on the left |
| Sprint (uses stamina) | Shift | SPRINT button |
| Jump overboard / climb iceberg / hop off | Space | JUMP button |
| Restart | R | |
| Mute | M | |

## Run locally

It's plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser.
